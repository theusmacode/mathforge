# ARCHITECTURE

- `src/core/` — lógica pura (sem React): `expression` (parser seguro), `fraction`, `number-theory`, `proportion`, `algebra`, `finance`, `geometry`, `basic`, `format`, `persist` (parsing/atualização de dados salvos), `types`.
- `src/features/modules.ts` — cada ferramenta numérica = `fields` + `compute(values) → Result`. Ferramentas com UI própria ficam em `customTools` (ex.: `Calculator.tsx`).
- `src/features/store.ts` — estado global de favoritos e histórico (`useSyncExternalStore`), gravando em LocalStorage (`mathforge.favorites`, `mathforge.history`, envelope `{v:1,data}`). Falha de armazenamento ou dado corrompido ⇒ começa vazio, sem quebrar.
- `src/registry/` — catálogo. O status “disponível” é derivado: existe módulo (ou custom tool) para o id.
- `src/pages/` — Dashboard, Category, Tool, Favorites, History.
- Histórico: gravado **somente** em ações do usuário (Calcular); repetição idêntica consecutiva é ignorada. “Reabrir” usa `location.state.inputs`.
- Testes: `src/tests/*.test.ts` (Vitest). Imports em `core/` e `features/modules.ts` usam extensão `.ts` para rodar também no Node puro.
- Convenções numéricas: ponto flutuante IEEE-754; frações e MMC/MDC exatos até 2^53−1; fatoração até 10¹².
- **Cálculo** (`core/calculus.ts`): `parse` → AST (`Node`), `evalNode`, `deriv`/`derivN` (simbólico), `integ`/`antiderivative` (subconjunto; lança `Unsupported`), `integrate` (Simpson/trapézio), `limitNumeric`, `newton`. Duplica a gramática do parser da calculadora de propósito: aqui é preciso uma árvore para derivar.
- **Discreta** (`core/discrete.ts`): lógica proposicional, conjuntos, bases (BigInt), aritmética modular, PA/PG, Fibonacci.
- `ToolModule.compute(values, texts?)`: campos `text: true` chegam em `texts`. `Result.table` renderiza tabelas.
- **Design system** (`styles/global.css`): tokens no `:root` (cores, espaçamento 4/8/12/16/24/32, raio 10), sem gradientes. Componentes por classe: `.btn/.primary`, `input/select`, `.stat`, `.tool-card`, `.table-wrap`, `.result/.out/.mono`, `.error`, `.badge`, `.empty`. Alterar cor da marca = `--green`.
- **Estatística** (`core/stats.ts`): leitura de dados (vírgula decimal), descritivas, percentil inclusivo (tipo 7), frequências (valores ou classes de Sturges).
- **Catálogo declarativo** (`features/defs/*.ts`): `def(id, nome, categoria, subcategoria, glifo, descrição, palavras-chave, campos, calcula)`. `kit.ts` tem `F("id|Rótulo|unid|flags")` (flags `o` opcional, `t` texto, `m` multilinha), `SEL` (select), `res`, `err`, `chk`. O mesmo `Def` alimenta o registro (metadados) e `modules` (cálculo): para criar uma ferramenta basta adicionar um `def` ao arquivo da área. `compute` é envolvido em try/catch: exceções viram mensagens de erro.
- **Novos motores**: `matrix` (Gauss, det, inversa, sistema), `poly` (aritmética e raízes racionais com BigInt), `prob` (erf, normal, binomial, regressão), `finance2` (Price/SAC, taxa implícita), `triangle` (LLL/LAL/ALA/LLA).
- **Interfaces por finalidade (v0.5)**: `features/kinds.ts` → `kindOf(tool)` escolhe 1 de 8 modelos (`calc, finance, matrix, stats, algebra, geometry, physics, analysis`) por id/categoria; `ToolShell.tsx` renderiza o workspace (entradas | resultados; `stack` para matrizes) e o conteúdo muda por modelo (ordem figura/KPIs, títulos, contador de dados, tabela de evolução, premissas). Resultados são calculados ao vivo; o botão Calcular grava no histórico.
- **Visuais** (`features/visuals.ts`): `visualFor(id, valores, textos)` devolve `{chart?, compare?}` usando os motores de `core/`; `modules.ts` anexa isso a todo resultado válido. Tipos em `core/types.ts` (`Chart`: line | bars | scatter | shape; `Compare`). Componentes: `ChartView`, `ShapeView` (figuras proporcionais), `MatrixGrid`.
- **Adicionar um modelo visual a uma ferramenta**: acrescente um `case` em `visualFor`. **Adicionar uma ferramenta**: um `def(...)` em `features/defs/`; o modelo é inferido por `kindOf`. Campos: flags `x`/`y` em `F()` = grade de matriz simples/aumentada; **não use “|” em rótulos**.
- Interfaces próprias preservadas: `Calculator.tsx`, `Grapher.tsx` (ver `customTools`).
- **Especificação por ferramenta (v0.6)**: `features/ui/specs.ts` (`SPECS[id]`: `layout`, `sentence` com `{campo}`, `editors`, `sliders`, `units`, `op`, `extras`). `features/ui/run.ts` (`runTool`) lê campos, converte unidades (`ui/units.ts`) e chama o cálculo existente, sem React (testável). `ui/Editors.tsx` reúne os editores. `ToolShell` monta a tela a partir da spec; `src/tests/specs.test.ts` garante que toda ferramenta tem spec e que enunciados, editores e sliders referenciam campos reais.
- **Nova ferramenta**: `def(...)` + uma entrada em `SPECS` (o teste falha se faltar) + (opcional) um `case` em `visualFor`. `INVENTARIO.md` e a checagem de renderização: `npx tsx scripts/smoke-render.tsx --inventory INVENTARIO.md`.
